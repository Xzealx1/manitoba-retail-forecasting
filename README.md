# Manitoba Retail Demand Forecasting

This project builds a machine learning forecasting system for retail demand using real or synthetic e-commerce data
Tech stack: Python, Pandas,SciKit-learn, Time-Series Models, Streamlit

## Project goals
- Clean and process retail data
- Build baseline and advanced forecasting models
- Evaluate models with metrics like RMSE, MAE, MAPE
- Produe a dashboard and final report for stakeholders

## Folder Structure
- `data/` raw + processed datasets
- `notebooks/` exploratory and modeling notebooks
- `src/` reusable Python scripts
- `reports/` figures and final markdown report
- `notes.md` ideas, planning, and observations
